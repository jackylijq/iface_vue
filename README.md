## 接口自动化框架 简介
接口自动化框架是一种用于支持Web接口自动化测试的工具和技术，它的主要目的是帮助开发人员和测试人员更快更有效地执行Web接口自动化测试。它可以通过脚本语言来实现Web接口自动化测试，并可以支持多种常见的Web接口自动化测试框架。
本框架前端使用vue3的技术实现前端接口用例的编辑，设计，维护等，后端使用python-flask的框架进行后端数据的存储，底层接口的执行。
整体框架设计：原子用例-集成用例-测试计划-测试报告，通过编写每个接口的原子用例，实现核心接口的基础调用编写，在集成用例中将各个模块的原子接口进行串接，达成模块级功能验证的效果，测试计划&报告主要用于后续的调度执行、结果查看的功能
